# 🦾 Tony Stark Brain

**สมุดจดกลางให้ AI อ่านก่อนเริ่มงานทุกครั้ง** ใช้ได้กับ Claude Code, Antigravity, Cursor, Codex และ AI ตัวอื่นที่อ่านไฟล์ได้

ใช้ AI เขียนโค้ดแล้วเจอแบบนี้ไหม
- เปิดแชทใหม่ทีไร ต้องเล่าโปรเจกต์ใหม่ทุกครั้ง
- AI แก้โค้ดให้หมด แต่เราไม่เข้าใจว่ามันทำอะไร
- โควต้า AI หมดกลางงาน ต้องไปเล่าใหม่ในอีกตัว

Tony Stark Brain แก้ 3 เรื่องนี้ด้วยโฟลเดอร์ Markdown ธรรมดาๆ ที่เก็บ **กฎ**, **งานค้าง** และ **ประวัติงาน** ของทุกโปรเจกต์ไว้ที่เดียว และออกแบบให้ **กิน token น้อย** (แนวคิด LLM Wiki ของ Andrej Karpathy: ไฟล์หลักเล็ก AI เปิดไฟล์ละเอียดเฉพาะตอนต้องใช้)

> 📘 **เริ่มที่นี่ →** [คู่มือใช้งาน (GUIDE.md)](GUIDE.md) ติดตั้งทีละขั้น (ดาวน์โหลด ZIP หรือใช้ GitHub ก็ได้) และวิธีใช้กับ **โปรเจกต์ใหม่** หรือ **โปรเจกต์ที่มีอยู่แล้ว เช่น งานบริษัท**

## ทำอะไรได้บ้าง

| พิมพ์ว่า | AI จะทำ |
|---|---|
| `เริ่มงาน` | อ่านสมุดจด เช็ก git แล้วสรุปว่าค้างอะไร ควรทำอะไรก่อน |
| `จบงาน` | จดว่าวันนี้ทำอะไรไป พรุ่งนี้ต้องทำอะไรต่อ |
| `สร้างฟีเจอร์ใหม่ <ชื่อ>` | ทำใบงานฟีเจอร์ ถามสิ่งที่ยังไม่ชัด แล้ววางแผนทีละขั้น |
| `สร้างโปรเจกต์ใหม่ชื่อ <ชื่อ>` | เพิ่มโปรเจกต์ใหม่เข้าสมุดจด และผูกโฟลเดอร์โค้ดให้ |
| `ผูกโปรเจกต์ที่มีอยู่แล้วชื่อ <ชื่อ>` | อ่านโค้ดเดิมแล้วสรุปลงสมุดจด โดยไม่แตะไฟล์ของทีม |
| `ส่งไม้ต่อ` | จดงานค้างแล้วให้ประโยคไปวางใน AI อีกตัว ทำต่อได้ทันที |
| สั่งงานโค้ดตามปกติ | **โหมดเรียน:** แสดงผลลัพธ์ที่จะได้ + แผน แล้วสอนทีละขั้นแบบ Before / After พร้อมคำอธิบายภาษาไทย ให้คุณพิมพ์เองและเข้าใจไปด้วย |
| `เสร็จแล้ว ตรวจสอบโค้ดให้หน่อย` | ตรวจโค้ดที่คุณเขียนในขั้นนั้น (✅ PASS ❌ FAIL ⚠️ WARNING) แล้วไปขั้นต่อไป |
| `ตอบรวดเดียว` | ข้ามทีละขั้น ได้คำตอบครบในข้อความเดียว |
| `Feedback: <อาการ>` | ทดสอบแล้วเจอปัญหา AI หาสาเหตุจากโค้ดจริงแล้วเสนอวิธีแก้ ถ้าเป็นข้อติเรื่องระบบจะจดลง `feedback.md` |
| `โหมดด่วน <งาน>` | **โหมดด่วน:** AI เขียนโค้ดให้จนจบ คุณ commit / MR เอง (พิมพ์ `กลับโหมดเรียน` เพื่อกลับ) |
| `แก้เลย` | อนุญาตให้ AI แก้ไฟล์จุดนั้นให้เลย |

## ติดตั้งแบบเร็ว (สำหรับคนที่ใช้ Git เป็นแล้ว)

ต้องมี **Git**, **Node.js 18+** และโปรแกรม AI อย่างน้อย 1 ตัว (เช่น Claude Code, Antigravity หรือ Codex)

1. กด **Use this template → Create a new repository** ตั้งเป็น **Private**
2. Clone ลงเครื่อง แล้วรันตัวติดตั้งในโฟลเดอร์นั้น
   ```powershell
   cd <โฟลเดอร์ไหนก็ได้>
   git clone https://github.com/<ชื่อคุณ>/my-second-brain.git
   cd my-second-brain
   powershell -ExecutionPolicy Bypass -File setup.ps1   # Windows
   bash setup.sh                                         # Mac / Linux
   ```
3. เปิดโฟลเดอร์โปรเจกต์โค้ดในโปรแกรม AI แล้วพิมพ์
   ```text
   สร้างโปรเจกต์ใหม่ชื่อ my-app ที่โฟลเดอร์นี้ สมุดจดอยู่ที่ <path สมุดจด>
   ```

ตัวติดตั้งจะเชื่อม Skills เข้ากับ Claude Code และ Antigravity ให้เอง ถ้าใช้ Cursor หรือ Codex ให้ใส่ในไฟล์กฎของโปรเจกต์ (`.cursorrules` หรือ `AGENTS.md`) ว่า `อ่าน <path สมุดจด>/AGENTS.md ก่อนเริ่มงาน`

ไม่อยากใช้ GitHub ก็ได้ กด **Code → Download ZIP** แทนข้อ 1–2 แล้วรันตัวติดตั้งในโฟลเดอร์ที่แตกไฟล์ออกมา

ติดปัญหา ดูหัวข้อ "เจอปัญหา?" ใน [คู่มือ](GUIDE.md)
