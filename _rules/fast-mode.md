# โหมดด่วน (Fast Mode) — AI ทำให้จนจบในรอบเดียว

> อ่านไฟล์นี้เฉพาะเมื่อผู้ใช้เปิดโหมดด่วน ใช้ได้ทั้ง Claude Code และ Antigravity
> ค่าเริ่มต้นของทุก session คือ **โหมดเรียน** (Mentor Mode: ผู้ใช้เขียนเอง AI สอนและตรวจ)

## เปิด / ปิด

- **เปิด:** ผู้ใช้พิมพ์ "โหมดด่วน" หรือ "ช่วยผมด้วย ผมไม่ไหวแล้ว"
- **ปิด:** ผู้ใช้พิมพ์ "กลับโหมดเรียน" หรือเปิด session ใหม่ (ยกเว้น `handoff.md` ระบุว่า `โหมด: ด่วน`)
- ตอบรับทุกครั้งที่สลับ 1 บรรทัด: `● **โหมดด่วน** — AI เขียนโค้ดให้จนจบ คุณ commit / push / MR เอง`

## ลำดับงาน

```
☐ 1. อ่านโจทย์ / การ์ดที่ผู้ใช้วางมา + status.md + core/rules.md ของโปรเจกต์
☐ 2. ผลลัพธ์ที่จะได้ + แผน → รอผู้ใช้ตอบ "ลุย" (ถามครั้งเดียว)
☐ 3. ลงมือทำทุกขั้นต่อกัน ไม่หยุดรอ "เสร็จแล้ว ตรวจสอบโค้ดให้หน่อย"
☐ 4. ตรวจตัวเอง + typecheck / lint / test / e2e ที่โปรเจกต์มี
☐ 5. สรุป: ไฟล์ที่แก้ (--stat), ผลคำสั่งตรวจจริง, สิ่งที่ยังไม่ได้ยืนยัน, ข้อความ commit พร้อมก๊อป
☐ 6. ผู้ใช้ commit / push / เปิด MR / ย้ายการ์ดเอง
☐ 7. อัปเดต status.md + log.md + "3 อย่างที่ควรกลับมาเรียนทีหลัง"
```

- ข้อ 2 ใช้รูปแบบ "ผลลัพธ์ที่จะได้" ตาม `_rules/response-format.md` แต่ไม่ต้องแตกทีละขั้นให้ผู้ใช้พิมพ์
- ระหว่างข้อ 3 รายงานความคืบหน้าสั้นๆ ด้วยแผน `☐ ▶ ☒` ในกล่องโค้ด ไม่ต้องแสดง Before/After ทุกจุด
- ตรวจในข้อ 4 ไม่ผ่าน → แก้ตาม **Escalation ladder** ใน `_rules/agent-ops.md` หัวข้อ 4 (ตรวจตัวเอง → เพิ่ม effort → ขึ้นรุ่น → รุ่นสูงสุดต้องขอก่อน)
- ติดเรื่อง business rule, API contract หรือข้อมูลที่ไม่แน่ใจ **ให้หยุดถาม ห้ามเดา** แม้จะรีบ

## ใช้ AI ช่วยหลายตัว (ถ้าโปรแกรมรองรับ)

- **Claude Code:** แจกงานให้ subagent ได้ตาม `_rules/agent-ops.md` (Haiku ค้นหา/อ่าน, Sonnet เขียนโค้ดตาม spec, ไม่เกิน 2 ตัว, กำหนดรุ่นทุกครั้ง)
- **Antigravity:** ถ้าไม่มี subagent ให้ทำเองทีละส่วนตามลำดับ ใช้รุ่นที่ผู้ใช้เลือกไว้ ห้ามบอกว่าแจกงานแล้วถ้าไม่ได้แจกจริง
- สองตัวห้ามแก้ไฟล์เดียวกันพร้อมกัน

## ห้ามแม้อยู่ในโหมดด่วน

- push, เปิด MR/PR, merge, deploy เอง — ยกเว้นผู้ใช้สั่งในข้อความนั้นชัดๆ
- แก้ไฟล์ที่ทีมใช้ร่วมกัน (config กลาง, CI, lock file ที่ไม่เกี่ยว) โดยไม่บอกก่อน
- แตะ secret, `.env`, ข้อมูลจริงของผู้ใช้ระบบ
- บอกว่า "เสร็จ/ผ่าน" โดยไม่มีผลคำสั่งตรวจจริง

## สรุปตอนจบ (รูปแบบ)

````
● **สรุปงาน (โหมดด่วน)** · เสร็จ 4/4
```
☒ 1. ...
```
**ไฟล์ที่แก้:** `src/a.ts`, `src/b.vue` (+120 −15)
**ตรวจแล้ว:** `npm run typecheck` ผ่าน · `npm test` ผ่าน 24/24
**ยังไม่ได้ยืนยัน:** ทดสอบบน staging
**ข้อความ commit:**
```
feat(users): เพิ่มปุ่ม export ผู้ใช้เป็น Excel
```
**กลับมาเรียนทีหลัง:** 1) streaming response 2) xlsx library 3) การจำกัดจำนวนแถว
**ต่อไป:** commit / push / เปิด MR แล้วย้ายการ์ด · พิมพ์ "กลับโหมดเรียน" เมื่อเสร็จงานด่วน
````

## ส่งไม้ต่อ (handoff)
