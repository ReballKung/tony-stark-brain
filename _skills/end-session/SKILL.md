# End Session

1. ตรวจของจริง: `git branch --show-current`, `git status --short`, `git log --oneline -5` ในทุก repo ที่แตะวันนี้
2. อัปเดต `<vault>/<project>/status.md` ตาม `_templates/status.md`:
   - ใส่วันที่ปัจจุบัน + ชื่อ AI ที่ใช้งาน
   - ย้ายงานที่เสร็จออกจาก "กำลังทำ"
   - เขียนหัวข้อ "ถัดไป" ให้คน (หรือ AI) ที่มาเปิดพรุ่งนี้ทำต่อได้ทันที
   - ยาวไม่เกิน 1 หน้า
3. เพิ่ม 1 บรรทัดท้าย `<vault>/<project>/log.md`:
   `- YYYY-MM-DD [ชื่อ AI] สิ่งที่ทำ → ผล / ถัดไป` (ใส่ commit hash ถ้ามี)
4. ถ้ามีการตัดสินใจสถาปัตยกรรมสำคัญ → เสนอสร้าง ADR จาก `_templates/adr.md` (ถามผู้ใช้ก่อน)
5. ตอบผู้ใช้: สรุป 3 บรรทัด (ทำอะไรไป / ค้างอะไร / พรุ่งนี้เริ่มที่ไหน)
